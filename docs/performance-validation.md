# 性能验证记录

本文记录主动视觉云台在 RK3568、ESP32-CAM 与 STM32F103 实机链路上的性能结果，并统一各指标的统计边界。仓库当前仅发布结果摘要；RKNN 模型产物、验证集清单和原始采集日志尚未随源码分发。

## 结果摘要

| 类别 | 基线 | 优化后 |
|---|---:|---:|
| 目标稳定时间 | 1.65 s | 1.12 s |
| 稳态中心误差 | 12.3 px | 5.6 px |
| 指令积压时延 | 240 ms | 65 ms |
| 人脸检测 mAP@0.5 | ONNX FP32：92.6% | RKNN INT8：91.7% |
| RK3568 NPU 纯推理延迟 | - | 15 ms |
| RK3568 单帧视觉处理延迟 | - | 42 ms |
| ESP32-CAM 至 STM32 P95 端到端时延 | - | 96 ms |

可靠通信压力测试使用 10 万条关键控制消息并注入 10% 应用层丢包，最终送达率为 99.99%。

## 指标口径

### 视觉闭环

- 对比对象：基础位置误差控制与加入误差平滑、控制死区、增量限幅后的控制器。
- 稳定时间：从目标首次形成有效检测到中心误差进入稳定区间并在观察窗口内不再越界的时间。
- 稳态误差：系统稳定后采样窗口内目标中心与画面中心二维像素偏差的均值。
- 摄像头、目标初始位置、控制频率、舵机供电及图像尺寸在两组测试中保持一致。

### 可靠通信

- 在应用层发送入口按固定概率丢弃 V1 消息，丢包比例设为 10%，保证试验可重复且不改变 COBS/CRC16 的差错检测行为。
- 关键命令最终送达率按“收到匹配 ACK 的唯一序列号数量 / 首次发送的唯一序列号数量”统计；重传帧不重复计入分母。
- STM32 以序列号和控制 epoch 过滤重复消息，执行计数用于检查命令是否发生重复执行。
- 积压时延对比 FIFO 顺序消费与 Latest 覆盖策略；从消息进入发送队列到实际出队发送计算等待时间。

### 模型与推理

- ONNX FP32 与 RKNN INT8 使用相同的人脸检测验证集、输入尺寸、置信度阈值、IoU 阈值和后处理流程。
- mAP@0.5 按 IoU=0.5 统计；量化前后下降 0.9 个百分点。
- NPU 纯推理延迟只统计 RKNN Runtime 的推理调用，不包含 JPEG 解码、缩放、颜色转换和 NMS。
- 单帧视觉处理延迟包含 JPEG 解码、模型预处理、NPU 推理、NMS 与目标中心计算，不包含 ESP32-CAM 网络采集时间。

### 端到端时延

- 起点为 ESP32-CAM 完成图像采集，终点为 STM32 接收对应控制消息并更新舵机控制量。
- P95 为全部有效样本按耗时升序排列后的第 95 百分位，不等同于平均时延或最大时延。
- 当前公布的 96 ms 为整条“采集—传输—检测—控制—执行”链路结果；42 ms 仅代表 RK3568 单帧视觉处理，二者统计边界不同。

## 结果使用边界

上述结果对应当前硬件组合、网络环境、模型输入与控制参数，不代表更换摄像头、图像尺寸、无线环境或模型后的固定性能。复现时应同时记录软件提交、RKNN Runtime 版本、输入尺寸、测试样本数和网络条件。
